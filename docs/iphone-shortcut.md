# iPhone 快捷指令设置

在 iPhone 的「快捷指令」App 中创建名为「断开校园网」的快捷指令：

1. 添加「URL」动作，内容设为 `https://ntfy.sh/`。
2. 添加「获取 URL 内容」动作，方法选择 `POST`，请求体选择 `JSON`。
3. 添加两个 JSON 字段：

   | 字段 | 值 |
   | --- | --- |
   | `topic` | 路由器 `/etc/campus-off.topic` 中的私密主题 |
   | `message` | `OFF` |

4. 保存。需要断开路由器 WAN 时，用手机流量运行这个快捷指令。

请勿把含有真实主题的快捷指令导出文件、分享链接或编辑页面截图公开。路由器断网后无法再通过 ntfy.sh 接收提前恢复指令；一小时后的恢复由路由器本地定时任务执行。
